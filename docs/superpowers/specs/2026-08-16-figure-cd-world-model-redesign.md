# 图 C、D 世界模型视觉重设计规格

日期：2026-08-16
范围：参赛方案图 C、图 D，以及与两图直接相关的正文引用和图片说明。

## 目标

从评审阅读和企业沟通两个场景出发，重新组织图 C、图 D 的信息层级，使读者在数秒内看懂：

1. 飞书 Aily 负责业务交互，AgentOS 负责任务编排；
2. 世界模型预测候选动作的后果、风险与不确定性；
3. 技能小脑执行受控原语，安全层拥有独立否决权；
4. 正常、恢复和人工介入共享同一套技能、状态与证据链。

主架构中的“VLA / 执行层”统一替换为“世界模型预测层”。论文名称 Harness VLA 和 Fast-WAM 的模型分类属于专有概念，不改写为不存在的名称；但它们不再占据系统主架构层。

## 方案选择

采用确定性 HTML/SVG 绘制并导出 PNG，而非生成式位图。

原因：两张图包含大量中文、技能编号和状态关系，SVG 更适合保证文字准确、箭头不穿越、颜色语义统一，并允许后续低成本修改。生成式图像只适合场景主视觉，不适合本次技术信息图。

## 共同视觉语言

- 画布：横向 16:10 左右，适合飞书文档与网页阅读；目标导出宽度至少 1600 px。
- 背景：深海军蓝；卡片使用略浅的蓝灰色，避免纯黑大面积压迫。
- 字体：系统中文无衬线字体，标题粗体，正文中等字重。
- 核心色：
  - 青色：世界模型、预测、状态更新；
  - 蓝色：正常技能执行；
  - 琥珀色：Fallback 与有限预算恢复；
  - 绿色：验证通过和完成；
  - 红色：安全否决、停车和人工介入。
- 只保留一套颜色图例；颜色同时配合文字标签，避免仅依赖颜色传意。
- 不使用斜穿节点的连线；箭头只沿主轴或正交折线移动。
- 最小正文与图例字号在原始导出图上不低于 20 px。

## 图 C：世界模型分层架构总览

### 标题

“分层智能架构：业务意图 → 后果预测 → 受控执行”

### 主体结构

采用四层纵向堆叠，每层使用“角色、输入输出、关键组件、验证证据”四类信息，但每类只保留最重要的 2–3 项。

1. **飞书 Aily 交互入口**
   - 自然语言任务解析；
   - 时效、优先级和位置约束；
   - 输出结构化任务意图。
2. **AgentOS 任务大脑**
   - 任务图与九技能白名单；
   - 状态记忆与 Scene Graph；
   - Fallback 策略和执行预算。
3. **世界模型预测层**
   - 融合观测、设备状态和历史事件；
   - 比较候选技能的下一状态、成功、风险和不确定性；
   - 输出技能选择建议与目标参数，不直接输出电机命令。
4. **技能小脑与安全执行层**
   - M4 规控、Isaac 物理执行和接触验证；
   - OBB / SAT 扫掠守卫与安全停车；
   - 执行结果回写世界模型和证据链。

层间数据流使用单一垂直主箭头；执行结果另用一条青色回路从第四层返回第三层，表达“执行后重新观察和更新”。右侧不再为每层复制“平台与证据”标题，而改为一条统一的“飞书协同与证据链”侧栏，列出任务、预测、技能、Fallback、视频和 Manifest 共用运行 ID。

### 边界声明

图中明确标注：当前 Demo 使用“物理仿真 + Scene Graph + 状态机 + 碰撞预测 + 失败记忆”的显式世界模型；学习型世界模型属于企业数据接入后的下一阶段，不能写成现有成果。

## 图 D：世界模型闭环与九技能执行链

### 标题

“世界模型闭环 × 九技能执行链 × 有限预算恢复”

### 主体结构

图的上半部分是世界模型闭环：

`观察状态 → 预测候选后果 → 选择白名单技能 → 执行与验证 → 更新状态`

下半部分采用三条平行泳道，禁止交叉连线：

1. **正常执行**
   - 九项技能按真实顺序编号 01–09；
   - 按“进入与感知、叉取、转运与放置”分为三个阶段组；
   - 末端为绿色 `COMPLETED · 9/9`。
2. **自动恢复**
   - 从“精准对位”节点垂直下接“首次对位失败”；
   - 经 `FB-01 横向修正` 后，用正交回路返回“精准对位”；
   - 标注恢复预算和“恢复后重新验证”，不画跨越其他节点的斜线。
3. **安全介入**
   - “连续识别失败”进入 `FB-02 切换观察位姿`；
   - 达到重试上限后进入 `FB-07 箱外安全停车`；
   - 末端为红色 `HUMAN REQUIRED`。

每个泳道末端仅显示终态、完成技能数和实测时长；详细事件数量放在图注或正文，避免图内信息过载。

### 世界模型在图 D 中的作用

- 每次技能执行后更新场景状态；
- 失败后不继续使用过期目标参数；
- 比较“重试、换观察位、安全停车”三个候选后果；
- AgentOS 仍负责预算和流程选择，安全层仍可独立否决。
