# 飞书复赛方案成稿设计

## 目标

将官方 40 强赛模板改写为一份面向评审、图文并茂且所有定量结论可追溯的参赛方案。文档标题为“【40强赛】仙工智能🤝鹰之团｜可验证的层次化 VLA 智能叉车卸货系统”。

## 内容结构

1. 参赛方案信息卡：团队、赛题、一句话摘要、成员分工、飞书 AI 能力。
2. 场景与痛点：前仓月台集装箱卸货的异常多、调试慢、责任难追溯问题。
3. 方案与创新：分层大脑—小脑架构、白名单技能链、Fallback、人机协同和证据链。
4. 前后对比：把传统脚本和端到端黑盒与本方案逐项比较。
5. 详细技术路线：四层架构、九技能链、Fast-WAM 接入边界、碰撞安全、Web 演示。
6. 价值与量化：严格分开“当前实测”和“试点目标”。
7. 体验与附件：在线 Demo、公开仓库、证据清单、企业合作路线图。

## 视觉策略

- 新生成一张无文字、物理尺度可信的仓储卸货主视觉。
- 现有图只作为信息参考；架构、技能链、证据链、价值和路线图保留可核验关系，并在正文中补充准确图注。
- 不采用未落地的场景迭代对比图，不让 AI 生成图承载精确数字。
- 每幅图紧跟其解释段落，避免装饰性堆图。

## 证据与边界

- 当前可声明：三类叉车录像、Fast-WAM 固定初态 5/5、3,029,546 次碰撞检查零违规、201 项 Python 测试和 50 项 JavaScript 断言。
- Fast-WAM 仅证明官方 LIBERO task 8 的接入闭环，不代表它直接控制叉车或具备通用成功率。
- 仿真原型尚未连接真实 SRC-5000、叉车安全 PLC 和实机传感器。
- 成本、切换时间和多机收益写为试点目标，不写成已实现收益。

## 发布范围

- 覆盖指定飞书文档现有模板正文并更新标题。
- 上传正文所需图片。
- 不修改分享权限，不提交比赛报名表，不向其他渠道发布。

## 验收

- 官方模板四类信息均有明确对应章节。
- 标题、正文、成员信息、链接、指标和限制与仓库事实一致。
- 飞书 API 回读能够找到全部一级章节、在线 Demo、仓库链接和关键指标。
- 图片块均有有效文件令牌，正文无模板占位词或评分说明。
