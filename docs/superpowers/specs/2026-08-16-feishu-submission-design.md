# 复赛方案 Markdown 成稿设计

## 目标

将官方 40 强赛模板改写为一份面向评审、图文并茂且所有定量结论可追溯的参赛方案。文档标题为“【40强赛】仙工智能🤝鹰之团｜世界模型驱动的分层智能叉车卸货系统”。主叙事使用世界模型；Harness VLA 与 Fast-WAM 仅在理论来源和模型专名语境中出现。

## 内容结构

1. 严格沿用官方模板的四个一级区块：参赛方案信息卡、方案成果展示、自由展示区、附录。
2. 方案成果展示内部依次使用模板标题：命题场景与痛点、方案优势/创新点、Before/After、具体方案说明、方案价值、体验入口与 Demo。
3. 四大评分维度只作为内容取舍原则，不在成稿中显示为章节或评分表。
4. 内容重点覆盖熟练叉车师傅供给下降、世界模型、AgentOS、技能链、Fallback、飞书协同、量化价值和证据链。
5. 自由展示区用 Harness VLA 的固定原语、记忆、闭环反馈与成功谓词支撑设计，明确世界模型是本方案的原创工程延伸。
6. 附录保留幕后故事、参考项目与文献、交付清单、证据索引和企业合作建议。

## 视觉策略

- 新生成一张无文字、物理尺度可信的仓储卸货主视觉，以及一张对象关系准确的 Fast-WAM 黑碗到黄盘主视觉。
- 现有图只作为信息参考；含旧 VLA 主架构文案的图片不进入成稿，世界模型架构改用可编辑 Mermaid 图，技能链、证据链和价值图保留可核验关系。
- 不采用未落地的场景迭代对比图，不让 AI 生成图承载精确数字。
- 每幅图紧跟其解释段落，避免装饰性堆图。

## 证据与边界

- 当前可声明：三类叉车录像、Fast-WAM 固定初态 5/5、3,029,546 次碰撞检查零违规、201 项 Python 测试和 50 项 JavaScript 断言。
- Fast-WAM 仅证明官方 LIBERO task 8 的接入闭环，不代表它直接控制叉车或具备通用成功率。
- 仿真原型尚未连接真实 SRC-5000、叉车安全 PLC 和实机传感器。
- 成本、切换时间和多机收益写为试点目标，不写成已实现收益。

## 交付范围

- 在仓库 `参赛方案/` 下生成一份可直接审阅的 Markdown 成稿。
- 使用相对路径引用仓库内图片，保留后续复制到飞书或其他平台的便利性。
- 不写入飞书，不修改分享权限，不提交比赛报名表，不向其他渠道发布。

## 验收

- 官方模板四类信息均有明确对应章节。
- 标题、正文、成员信息、链接、指标和限制与仓库事实一致。
- Markdown 能够找到全部一级章节、在线 Demo、仓库链接和关键指标。
- 图片引用均指向真实存在的本地文件，正文无模板占位词或评分说明。
